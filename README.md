# GitHub Get

GitHub Get adds a **Download** button to GitHub repositories.

Because apparently finding the correct file under **Releases - Assets - random-platform-name-x86_64-final-final.zip** is a skill now.

GitHub Get looks at the available release files and makes downloading the right one a lot less annoying.

Useful for:

* people who can't find the download button
* people who can find it but don't want to play artifact roulette
* people who just want the app, not the source code
* everyone who has ever stared at six nearly identical `.zip` files

## What it does

Open a GitHub repository.

See **Download**.

Click **Download**.

Revolutionary stuff.

It can account for things like different operating systems, architectures, release channels, and multiple downloadable files when necessary.

## Installation

Install the extension and visit GitHub.

And yes, once you have GitHub Get installed, you could theoretically use GitHub Get to download GitHub Get.
